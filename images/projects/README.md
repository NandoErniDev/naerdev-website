# Project screenshots

Put a cover and up to three detail screens in each project folder:

```
images/projects/<slug>/cover.jpg      16:10 hero screenshot
images/projects/<slug>/screen-01.jpg  4:3 detail
images/projects/<slug>/screen-02.jpg
images/projects/<slug>/screen-03.jpg
```

The site shows a designed placeholder until a file exists. JPG, PNG and WebP all work.
